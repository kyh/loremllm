---
title: Teams
description: Invite teammates, set roles and share mock URLs across a team.
---

Invite people under **Settings → Members**. Sign-in works with email and password or GitHub.

## Roles

| Role   | Can                                                    |
| ------ | ------------------------------------------------------ |
| Owner  | Everything, including billing and deleting the project |
| Admin  | Manage members, keys and every mock                    |
| Editor | Create and edit mocks, read requests                   |
| Viewer | Read mocks and requests                                |

## Sharing

Every mock URL is stable, so a team can point local dev, previews, CI and Storybook at the same mock. Changes publish to everyone at once. Pin a [version](/docs/platform/projects#versions) when a branch needs the old behaviour.
