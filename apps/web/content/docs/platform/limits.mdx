---
title: Limits
description: Rate limits, payload sizes and retention.
---

| Limit                            | Free     | Team      |
| -------------------------------- | -------- | --------- |
| Requests per minute, per project | 600      | 6,000     |
| Mocks per project                | 20       | Unlimited |
| Scenarios per mock               | 100      | 1,000     |
| Request body                     | 4 MB     | 20 MB     |
| Inspector retention              | 7 days   | 30 days   |
| Conversation state               | 24 hours | 24 hours  |

Hitting a LoremLLM limit returns `429` with a `loremllm-rate-limit` problem, which is different from a scripted `error(429)`. The `x-loremllm-limit` header tells them apart.

The local server and in-process packages have no limits.
