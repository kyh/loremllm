title: Headers

## Request headers

| Header                     | Effect                                                |
| -------------------------- | ----------------------------------------------------- |
| `loremllm-conversation-id` | Sets the [conversation id](/docs/mocks/conversations) |
| `loremllm-latency`         | `none`, `fast` or `real` stream timing                |
| `loremllm-seed`            | Overrides the seed for random replies                 |
| `loremllm-version`         | Pins a mock version                                   |
| `loremllm-scenario`        | Forces a scenario by name, skipping matching          |

Any other header can be matched with `when: { header }`.

## Response headers

| Header                | Value                                                                   |
| --------------------- | ----------------------------------------------------------------------- |
| `loremllm-scenario`   | Name or index of the matched scenario                                   |
| `loremllm-result`     | Name or index of the `oneOf` result routing picked                      |
| `loremllm-request-id` | Id to look up in the inspector                                          |
| `loremllm-version`    | Mock version that answered                                              |
| `loremllm-limit`      | Present only when a platform limit, not a scenario, caused the response |
